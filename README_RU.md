# MineRust Raid Addon (Forge 1.12.2)

Отдельный аддон к **MineRust Addons**. Нужны ОБА jar в папке `mods`.

## Что делает
- Сачель и C4 из MineRust вешаются **только на боковую сторону** стен/дверей MineRust (и железной двери).
  Плашмя (на пол/потолок) повесить нельзя — баг с зависшими в воздухе зарядами исчезает.
- Заряд всегда ровно ложится на стену той стороной, по которой кликнул, независимо от угла камеры.
- На одно место можно повесить до 4 зарядов (клик по заряду или по той же стене) — они взрываются вместе.
- Шанс взрыва сачеля — 80% (каждый сачель отдельно), C4 — 100%.
- Железная дверь: 2 сачеля или 1 C4 или 2 ракеты.
- Ракетница (3D модель) + ракеты (видно летящую ракету с дымом и огнём). Взрыв бьёт область 3x3x3.
  Ракет нужно: дерево 2, камень 4, металл 8, МВК 12, железная дверь 2, солома 1.
- У повреждённых стен и дверей видны трещины (эффект поломки), повреждение сохраняется в мире.
- Взрывы аддона НЕ ломают обычные блоки — урон получают только стены/двери из списков.

Все числа меняются в `config/minerustraid.cfg` (появится после первого запуска).

## Крафты
- Ракетница: `III / RSI / I__` (I — железо, R — редстоун, S — палка)
- Ракеты x2: `_T_ / GIG / _G_` (T — динамит, G — порох, I — железо)

## Как собрать jar через GitHub
1. Создай новый репозиторий на github.com (можно приватный).
2. Распакуй ZIP и загрузи ВСЁ содержимое в корень репозитория (Add file → Upload files).
   Важно: папка `.github` (скрытая) тоже должна попасть в репозиторий.
   Если она не загрузилась — Add file → Create new file, имя `.github/workflows/build.yml`,
   вставь туда содержимое этого файла из архива.
3. Открой вкладку **Actions** → workflow **Build mod** → если не запустился сам, нажми **Run workflow**.
4. Через ~5–10 минут открой завершённый запуск → внизу **Artifacts** → скачай `MineRustRaidAddon`.
   Внутри будет `MineRustRaidAddon-1.0.0.jar`.
5. Положи его в `mods` вместе с MineRust Addons.

Если сборка упала — открой лог шага Build и пришли текст ошибки.
